## Межі застосування

- Навички не замінюють правила AGENTS.md і вказівки користувача.
- Для поточного стека доречні довідники React/TypeScript, загальний frontend та Express. Специфічні правила Colyseus/WebSocket треба перевіряти окремо за реальною реалізацією.
- Встановлення не запускає аудит, не змінює код чи налаштування доступу, не публікує проєкт.
- Playwright CLI не додано: у поточній сесії є засоби керування браузером; цей архівний навик не потрібен для дублювання їх.
- Навички деплою не додано: хостинг ще не обрано.
- Уже доступні системні навички та інструменти документів не дублювались.
