# Rooms module

- domain/: правила кімнати й обмеження гравців.
- application/: створення кімнати, приєднання, відновлення сесії.
- ports/: інтерфейси збереження та інших зовнішніх залежностей.

Colyseus Room буде адаптером у transport/realtime. Він перевіряє повідомлення й викликає сценарії application. Серверна частина використовує шари domain/application/infrastructure; MVVM застосовується до клієнтського інтерфейсу.
