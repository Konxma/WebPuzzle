# WebPuzzle

Спільні пазли в браузері. В одній кімнаті можуть грати до 8 людей. Демо на 24 деталі, власні фото, 1–3000 деталей і автозбереження.

## Запуск на Windows

1. [Завантажте WebPuzzle.exe для Windows x64](https://github.com/Konxma/WebPuzzle/releases/download/v0.2.0/WebPuzzle.exe).
2. Відкрийте файл і натисніть **«Грати»**. Під час першого запуску лаунчер сам підготує файли.
3. Залиште лаунчер відкритим під час гри. Щоб завершити, натисніть **«Зупинити гру»**.

Лаунчер відкривається у світлій темі. Кнопка **«Темна тема»** перемикає оформлення. Через **«Змінити фото»** можна вибрати JPG або PNG для лаунчера й початкового пазла в браузері.

Для запуску через `.cmd` є [запасний ZIP](https://github.com/Konxma/WebPuzzle/releases/download/v0.2.0/WebPuzzle-Windows-x64.zip). Розпакуйте його та відкрийте **«Запустити WebPuzzle.cmd»**. Встановлювати Node.js і вводити команди не потрібно. Для завантаження потрібен доступ до репозиторію.

## Гра з друзями

Створіть пазл і відкрийте QR-код у панелі кімнати або скопіюйте посилання. До семи гостей можуть приєднатися з телефона, планшета чи комп’ютера в тій самій локальній мережі. Гостям достатньо браузера.

## Розробка

Потрібні Node.js 22 і npm. У папці проєкту виконайте:

```powershell
npm ci
npm run dev
```

Відкрийте [localhost:5173](http://localhost:5173). Для гри в локальній мережі з вихідного коду запустіть `Start.cmd` або `npm run dev:lan`.

```powershell
npm run typecheck
npm run build
npm test
npm run test:saves
```
