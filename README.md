# WebPuzzle

Спільні пазли в браузері для 1–3 гравців. Демо на 24 деталі, власні фото, 1–3000 деталей і автозбереження.

## Запуск на Windows

1. [Завантажте WebPuzzle для Windows x64](https://github.com/Konxma/WebPuzzle/releases/download/v0.1.0/WebPuzzle-Windows-x64.zip).
2. Натисніть правою кнопкою на ZIP і виберіть **«Видобути все»**.
3. У розпакованій папці двічі натисніть **«Запустити WebPuzzle»**. Гра відкриється в браузері. Залиште вікно запуску відкритим під час гри.

У пакеті вже є Node.js. Для завантаження з GitHub потрібен доступ до репозиторію.

## Гра з друзями

Створіть пазл і відкрийте QR-код у панелі кімнати або скопіюйте посилання. До двох гостей можуть приєднатися з телефона, планшета чи комп’ютера в тій самій локальній мережі. Гостям достатньо браузера.

## Розробка

Потрібні Node.js 22 і npm. У папці проєкту виконайте:

```powershell
npm ci
npm run dev
```

Відкрийте [localhost:5173](http://localhost:5173). Для гри в локальній мережі з вихідного коду запустіть `Start.cmd` або `npm run dev:lan`.

```powershell
npm run typecheck
npm run build
npm test
npm run test:saves
```
