# WebPuzzle

Спільні пазли від 1 до 3000 деталей для двох гравців у браузері на ПК. На головній одразу відкривається демо на 24 деталі.

## Що працює

- Створення приватної кімнати та приєднання за посиланням або кодом; максимум двоє гравців.
- Перед створенням виберіть «Тиху затоку» або власне фото, кількість і форму деталей. Попередній перегляд показує розрізи картини, які можна збільшити.
- Для короткого знайомства виберіть «24 · Демо». Також можна задати точну кількість, включно з простими числами, наприклад 997.
- Перетягування деталей, з’єднання сусідів у рухомі групи та прив’язування до рамки.
- Серверне блокування всієї групи за одним гравцем. Інший гравець бачить її приглушеною.
- PixiJS-поле, масштабування коліщатком/кнопками та рух столу за порожнє місце.
- Взята деталь або вся з’єднана група підсвічується теплим контуром; після відпускання підсвічування зникає. Серверне блокування групи зберігається.
- Поле перемальовується за змінами замість безперервного циклу. Рух миші об’єднується в одне оновлення на кадр; мережевий рух оновлює відповідну групу, а не весь стіл.
- Зразок картини, прогрес, завершення, список гравців, запрошення.
- Темна тема зберігається у браузері. Кнопки вгорі дозволяють сховати панель кімнати й розгорнути гру на весь екран.
- Власник кімнати може видалити гостя. Після виходу власника його роль переходить до гравця, який залишився.
- Автозбереження після відпускання деталі або перенесення в лоток. Збережені пазли можна продовжити після перезапуску.
- Лотки та фільтр «Лише краї» власник кімнати вмикає через «Налаштування пазла» на ігровому полі.
- Натисніть «Додати лоток», щоб створити спільний лоток для обох гравців. У кімнаті може бути до восьми лотків. Відкрийте лоток, щоб перейменувати його, або натисніть «Видалити лоток», щоб повернути його деталі на стіл. «Лише краї» показує деталі рамки.
- Камера та деталі рухаються в межах просторого столу з невидимими краями. Кнопка «Увесь стіл» повертає повний вигляд.
- Правий клік по столу відкриває керування. «Зафіксувати вид» блокує переміщення і масштаб камери. За замовчуванням перший клік бере деталь, а другий кладе її. Esc повертає деталь туди, звідки її взяли. Щоб перейти до звичайного перетягування, вимкніть «Перенесення кліками» в меню правої кнопки.
- Власні фото JPG, PNG або WebP до 25 МБ. Гра підганяє зображення під пропорції поля й використовує його для деталей та зразка.
- Повернення після короткої втрати зв’язку чи оновлення сторінки в тій самій вкладці (до 60 секунд).

Початкова картина «Тиха затока» — оригінальна векторна ілюстрація цього проєкту.

## Запуск

Двічі натисніть **Start.cmd** у папці проєкту. Він одразу запускає гру для двох в одній локальній мережі. Відкрийте адресу з вікна запуску, створіть кімнату й надішліть її посилання другому гравцеві. На другому ПК достатньо браузера.

У PowerShell:

```powershell
cd C:\Users\vadim\Desktop\WebPuzzle
npm.cmd install
npm.cmd run dev
```

Відкрити http://127.0.0.1:5173.
Після першого встановлення достатньо npm.cmd run dev.
Сервер: http://127.0.0.1:3001/api/health.

### Гра в домашній мережі

З командного рядка той самий запуск доступний через `npm.cmd run dev:lan`. Залишайте вікно відкритим під час гри; для зупинки натисніть Ctrl+C.

У вікні запуску є блок **«ЗАПРОШЕННЯ ДЛЯ ОДНІЄЇ МЕРЕЖІ»**: він показує повне мережеве посилання на активну кімнату та автоматично копіює його. Достатньо вставити другу через Ctrl+V. Якщо кімнати ще немає, спочатку натисніть «Створити кімнату» в браузері — вікно запуску підхопить її автоматично. Це працює і коли гру відкрито через localhost.

Якщо гра вже працює, повторний запуск показує адресу та стежить за запрошенням без запуску другого сервера. Таке повторне вікно можна закрити: активні кімнати продовжать працювати у попередньому запуску. Для зупинки перегляду запрошення натисніть Ctrl+C.

Запуск виведе адресу цього ПК, наприклад `http://10.0.0.57:5174/`. Відкрийте **цю саму адресу на обох комп’ютерах**, підключених до одного роутера. Створіть кімнату, а другому гравцю передайте посилання з кімнати або її код. Якщо браузер не дозволяє копіювання на HTTP, виділіть адресу в полі запрошення та натисніть Ctrl+C. Другому ПК достатньо браузера — встановлювати проєкт не потрібно.

Кнопка «Копіювати посилання» працює також на HTTP у домашній мережі. Якщо господар відкрив гру через localhost, поле запрошення автоматично використовує адресу активного LAN-запуску. Копіюйте запрошення кнопкою в кімнаті: адреса `127.0.0.1` з рядка браузера працює лише на вашому ПК.

Запуск використовує вже активний сервер кімнат на 3001, зберігаючи поточні ігри. Якщо сервер відсутній, він збере та запустить його самостійно. База даних для цього не потрібна. Якщо використовується сервер з іншого вікна запуску, це вікно теж має залишатися відкритим.

Правило брандмауера налаштовується один раз: запустіть PowerShell від адміністратора та виконайте `powershell.exe -ExecutionPolicy Bypass -File C:\Users\vadim\Desktop\WebPuzzle\scripts\allow-lan.ps1`. Правило дозволяє Node.js приймати TCP 5174 лише з локальної підмережі. Видалення правила: `Remove-NetFirewallRule -Name WebPazle-Home-LAN` у PowerShell адміністратора.

Якщо адреса ПК зміниться після перепідключення Wi-Fi, використовуйте нову адресу з вікна запуску. Гостьова Wi-Fi мережа може ізолювати пристрої один від одного.

## Перевірки

```powershell
npm.cmd run typecheck
npm.cmd run build
npm.cmd test
npm.cmd run test:saves
# З працюючим сервером:
npm.cmd run test:rooms
```

Тести domain перевіряють точну кількість, площу, симетричні контури, сусідство, блокування, з’єднання і завершення. Інтеграційні тести підключають реальні клієнти Colyseus: третій гравець відхиляється, рух передається, чужий рух блокується, перепідключення повертає стан. Є перевірки 1/1000/3000 та відмови для некоректних кількостей.

## Структура та MVVM

Стек, ключові файли й потік даних описані у [довіднику для наступного чату](docs/ARCHITECTURE.md).

```text
apps/client/src/
  app/                         складання залежностей і стилі
  features/lobby/
    models/                    інтерфейси сервісів
    viewmodels/                вибір кількості, створення/вхід
    views/                     React-екран
  features/puzzle/
    models/                    інтерфейс кімнати
    viewmodels/                стан екрана та команди гравця
    views/                     панелі, контейнер поля
    rendering/                 PixiJS, текстури, камера, вказівник
  infrastructure/http/         перевірка сервера
  infrastructure/realtime/     адаптер Colyseus
  shared/mvvm/                 спостережуваний ViewModel
  shared/ui/                   обгортка Gentleface
apps/server/src/
  transport/realtime/          Colyseus PuzzleRoom, перевірка команд
  infrastructure/database/     початкова схема Drizzle
packages/shared/src/
  domain/                      геометрія, стан груп, серверні правила
  contracts/                   мережеві повідомлення
```

View викликає команди ViewModel. ViewModel залежить від інтерфейсу кімнати, а не від SDK чи PixiJS. Domain не залежить від React, мережі або бази. Переміщення миші та кадри не проходять через React.

При вході надсилається знімок гри; під час руху — лише ідентифікатор групи, її зміщення та власник, максимум близько 20 разів на секунду. При з’єднанні надсилається змінена група.

## Поточні обмеження

При обриві зв’язку сервер тримає місце гравця до 60 секунд. Після остаточного виходу обох гравців або перезапуску кімната закривається, а прогрес і фото залишаються в `.data` на ПК, де запущена гра. Гравець, який створив пазл, може натиснути **«Продовжити»** в тому самому браузері за тією самою адресою гри. Якщо гра відкрила нову кімнату, надішліть другому гравцеві її нове запрошення.

Щоб перекласти деталь, перетягніть її на назву лотка. Натисніть назву, щоб подивитися вміст. Перетягніть деталь на **«Стіл»**, щоб повернути її до складання. Поки деталь у лотку, вона може переміщуватися всередині нього, а з’єднання й фіксація відбуваються на столі.
